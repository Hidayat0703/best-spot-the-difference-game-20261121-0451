Twin Valley — a spot-the-difference game: two near-identical pictures side by side in three hand-drawn scenes (Sunny Meadow, Harbor at Dusk, Mountain Camp), 7 then 8 then 10 fair-but-hidden differences, click to mark each find with a ring and check, limited hints, and a countdown timer you can feel.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network: serve `game/` with any static server. Sound is synthesized live with WebAudio.

Screenshots are deterministic scenes from the game's own code: `?shot=cover|meadow|camp|complete&seed=1`.
